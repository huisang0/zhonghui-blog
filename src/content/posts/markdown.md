# 一级标题

段落之间使用空行进行分隔。

第二段文本。_斜体_，**粗体**，还有`等宽代码`。无序列表写法如下：

- 第一项
- 第二项
- 第三项

注意：除去星号标记，实际正文内容从第四列位置开始。

> 引用块可以这样写。
>
> 可以跨多个段落，只要你愿意。

使用三个短横线代表长破折号。两个短横线用于表示数值范围（例如：“本书的第12--14章节”）。三个点`...`会被转换为省略号。支持Unicode字符☺。

## 二级标题

这是有序列表：

1. 第一条
2. 第二条
3. 第三条

同样注意正文内容从左侧4个字符位置开始。下面是代码示例：

    # 简单演示...
    for i in 1 .. 10 { do-something(i) }

如你所见，缩进4个空格即可。除此之外，也可以使用围栏代码块：

```
define foobar() {
    print "欢迎来到这里！";
}
```

(复制和粘贴将更加简单)。围栏代码块还可以指定编程语言实现语法高亮：

```python
import time
# 快速数到十
for i in range(10):
    # 但不要太快
    time.sleep(0.5)
    print i
```

### 三级标题

嵌套列表示例：

1. 准备这些食材：

    - 胡萝卜
    - 芹菜
    - 小扁豆

2. 将水烧开。

3. 将全部食材倒入锅中，执行下面步骤：

        取出木勺
        揭开锅盖
        进行搅拌
        盖上锅盖
        将木勺小心架在锅把手
        等待 10 分钟
        返回第一步（或者直接关火）

    小心不要碰掉木勺。

再次注意文本都从 4 空格缩进处开始，包括上面第 3 条的续行内容。

这里是链接示例：[访问网站](http://foo.bar)、[本地文档](local-doc.html)以及[本文的二级标题](#二级标题)。这里是脚注[^1]。

[^1]: 脚注文本写在这。

表格示例：

尺码 材料 颜色

9 皮革 棕色
10 帆布 自然色
11 玻璃 透明

表：鞋子尺码、材质与颜色。

Pandoc 同样支持多行表格：

关键词 文本

---

红色 落日、苹果，以及其他红色事物。

绿色 树叶、青草、青蛙，以及其他不容易成为的事物。

---

每一组术语与定义之间建议空一行，排版效果会更好。

行块写法：

| 第一行
| 第二行
| 第三行

图片写法示例：

[//]: # (![example image]&#40;./demo-banner.png "An exemplary image"&#41;)
